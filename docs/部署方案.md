| 软件 | 版本要求 | 说明 |
|------|---------|------|

## 四、凭证配置

### 4.1 获取美团凭证

美团经营宝需要登录凭证才能调用 API。请在已登录美团的电脑上导出凭证文件：

**凭证文件包括：**
1. `auth/auth.json` - Playwright 登录态（可复用数周）
2. `auth/credentials.json` - Cookie + mtgsig（会过期）

### 4.2 凭证导出步骤

1. 在本地电脑上确保已登录美团：https://e.dianping.com
2. 运行凭证获取脚本：
```bash
python common/credentials.py
```
3. 脚本会启动浏览器并保存凭证到 `auth/` 目录
4. 将 `auth/` 目录下的所有文件上传到服务器的 `auth/` 目录

### 4.3 凭证文件说明

| 文件 | 用途 | 过期时间 |
|------|------|---------|
| auth.json | Playwright 浏览器上下文 | 数周 |
| credentials.json | API 请求凭证 | 数天 |

**注意：** 如果 API 返回 401/403 错误，说明凭证已过期，需要重新获取。

## 五、服务部署

### 5.1 方式一：直接运行（开发/测试）

```bash
# 激活虚拟环境
source venv/bin/activate

# 启动 Web 服务
python -m web.api

# 服务地址：http://服务器IP:5000
```

### 5.2 方式二：使用 Gunicorn（生产环境推荐）

```bash
# 安装 gunicorn
pip install gunicorn

# 启动服务（后台运行）
nohup gunicorn -w 2 -b 0.0.0.0:5000 'web.api:app' --timeout 120 --access-logfile logs/access.log --error-logfile logs/error.log &

# 参数说明：
# -w 2: 2个工作进程
# -b 0.0.0.0:5000: 监听地址和端口
# --timeout 120: 请求超时120秒（Excel生成可能需要较长时间）
```

### 5.3 方式三：使用 Supervisor 管理进程（推荐）

#### 5.3.1 安装 Supervisor

**Ubuntu / Debian:**
```bash
sudo apt install supervisor
```

**CentOS:**
```bash
sudo yum install epel-release
sudo yum install supervisor
```

#### 5.3.2 配置 Supervisor

创建配置文件 `/etc/supervisor/conf.d/meituan.conf`：

```ini
[program:meituan]
command=/path/to/meituan/venv/bin/gunicorn -w 2 -b 0.0.0.0:5000 'web.api:app' --timeout 300
directory=/path/to/meituan
user=www-data
autostart=true
autorestart=true
stdout_logfile=/path/to/meituan/logs/supervisor.log
stderr_logfile=/path/to/meituan/logs/supervisor_error.log
```

#### 5.3.3 启动服务

```bash
# 创建日志目录
mkdir -p /path/to/meituan/logs

# 更新 supervisor 配置
sudo supervisorctl reread
sudo supervisorctl update

# 启动服务
sudo supervisorctl start meituan

# 查看服务状态
sudo supervisorctl status meituan
```

## 六、开机自启动配置

### 6.1 Linux systemd 服务

创建服务文件 `/etc/systemd/system/meituan.service`：

```ini
[Unit]
Description=Meituan Business Automation Service
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/path/to/meituan
Environment="PATH=/path/to/meituan/venv/bin"
ExecStart=/path/to/meituan/venv/bin/gunicorn -w 2 -b 0.0.0.0:5000 'web.api:app' --timeout 300
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

启用服务：
```bash
sudo systemctl daemon-reload
sudo systemctl enable meituan
sudo systemctl start meituan
sudo systemctl status meituan
```

### 6.2 Windows 计划任务

1. 打开 "任务计划程序"
2. 创建基本任务
3. 设置触发器为 "计算机启动"
4. 设置操作：启动程序
   - 程序：`C:\path\to\meituan\venv\Scripts\python.exe`
   - 参数：`-m web.api`
   - 起始位置：`C:\path\to\meituan`

## 七、Nginx 反向代理配置（可选）

### 7.1 安装 Nginx

**Ubuntu / Debian:**
```bash
sudo apt install nginx
```

**CentOS:**
```bash
sudo yum install nginx
```

### 7.2 配置反向代理

创建配置文件 `/etc/nginx/conf.d/meituan.conf`：

```nginx
server {
    listen 80;
    server_name your-domain.com;  # 替换为您的域名或IP

    client_max_body_size 100M;  # 允许上传大文件

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;

        # 超时设置（Excel生成需要较长时间）
        proxy_connect_timeout 300s;
        proxy_send_timeout 300s;
        proxy_read_timeout 300s;
    }
}
```

### 7.3 启用配置

```bash
# 测试配置
sudo nginx -t

# 重启 Nginx
sudo systemctl restart nginx
```

### 7.4 配置 HTTPS（推荐）

使用 Let's Encrypt 免费证书：

```bash
# 安装 certbot
sudo apt install certbot python3-certbot-nginx

# 获取证书
sudo certbot --nginx -d your-domain.com

# 自动续期已配置
```

## 八、防火墙配置

### 8.1 Linux 防火墙

```bash
# Ubuntu/Debian (ufw)
sudo ufw allow 22/tcp   # SSH
sudo ufw allow 80/tcp   # HTTP
sudo ufw allow 443/tcp  # HTTPS
sudo ufw enable

# CentOS (firewalld)
sudo firewall-cmd --permanent --add-port=22/tcp
sudo firewall-cmd --permanent --add-port=80/tcp
sudo firewall-cmd --permanent --add-port=443/tcp
sudo firewall-cmd --reload
```

### 8.2 检查端口是否开放

```bash
# Linux
sudo netstat -tlnp | grep 5000

# Windows
netstat -ano | findstr 5000
```

## 十一、常见问题排查

### 11.1 API 返回 401/403 错误

**原因：** 凭证已过期

**解决方案：**
1. 更新本地浏览器登录态
2. 重新运行凭证获取脚本
3. 将新的 `auth/auth.json` 和 `auth/credentials.json` 上传到服务器

### 11.2 Excel 生成失败

**原因：** 请求超时或内存不足

**解决方案：**
1. 增加 Gunicorn 超时时间：`--timeout 300`
2. 增加工作进程内存限制
3. 检查磁盘空间是否充足

### 11.3 Playwright 浏览器启动失败

**原因：** 缺少浏览器依赖或浏览器未安装

**解决方案：**
```bash
# 重新安装浏览器
playwright install chromium

# 安装系统依赖（Ubuntu）
playwright install-deps
```

### 11.4 端口被占用

**检查端口占用：**
```bash
# Linux
lsof -i :5000

# Windows
netstat -ano | findstr 5000
```

**解决：** 终止占用端口的进程或修改服务端口

### 11.5 多进程导致旧代码问题

**原因：** 多次启动服务导致多个旧进程占用端口

**症状：** 修改代码后API仍使用旧版本

**解决方案：**
```bash
# 终止所有 Python 进程
taskkill //F //IM python.exe  # Windows
pkill -f python               # Linux

# 确认只有一个进程
netstat -ano | grep 5000

# 重新启动服务
sudo supervisorctl restart meituan
```
